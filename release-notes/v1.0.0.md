# 闪电记课 v1.0.0

首个公开版本。

## 功能

- **记课**：学校 / 班级 / 课程三级联动，自动带出单价（支持按学校覆盖）；常用时间段一键选；0.5 步进课时。
- **结算周期**：起始日可配（如每月 26 号起），首页按周期统计课时与预计课酬。
- **状态流转**：草稿 → 已确认 → 已结算；已结算锁定不可改。
- **报销单**：明细按日期自动归档成月度单据，附号由导出顺序生成，与 Excel 凭证区严格对应；无票明细整行标红。
- **导出**：课时对账表（CSV / Excel）、月度报销单（xlsx 内嵌凭证截图）、全量备份（zip 含截图）。
- **隐私**：零系统权限、不联网，数据只存本机；首启隐私政策告知，应用内可查阅全文。

## 安装说明

- 下载下方 `lesson_ledger_1.0.0+6_universal.apk`（通用包，arm64 / armeabi-v7a / x86_64 全含）。
- 安装时如提示「未知来源应用」，允许一次即可。
- 首次启动会写入示例数据，可直接体验导出；在「我的 → 清空全部数据」可归零。
